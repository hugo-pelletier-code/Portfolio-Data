# Portfolio-Data

Bienvenue sur mon portfolio dédié à la data. Vous y découvrirez une sélection de projets réalisés en Python et SQL, illustrant ma capacité à explorer, transformer, analyser et valoriser les données dans des contextes variés.

Ces projets mettent en lumière :
- Des analyses exploratoires de données complètes avec visualisations interactives ou scripts clairs et documentés 
- Des traitements automatisés de données structurées via Python (Pandas, NumPy, Matplotlib/Seaborn) 
- Des requêtes SQL complexes, utilisées pour extraire des insights à partir de jeux de données volumineux ou relationnels

Mon objectif est de rendre les données accessibles, compréhensibles et exploitables. Chaque projet est pensé pour répondre à une problématique concrète, en alliant rigueur technique et esprit analytique.

Au-delà des compétences techniques, je mets un point d’honneur à développer une approche stratégique et orientée solution. Je cherche à comprendre le “pourquoi” derrière les chiffres, pour aider à la prise de décision et à la création de valeur.
